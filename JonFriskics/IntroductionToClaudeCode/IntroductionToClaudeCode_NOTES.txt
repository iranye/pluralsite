# Prompts used in the course

## Concert ticket marketplace site

### 01. Initial prompt to create the prototype

Generate a prototype of a website for selling concert tickets.

I want a page that lists available concert tickets.

That ticket information should include the artist name, venue name, event date, and ticket price.

Make up fake artist and venue names to use as placeholders and use a placeholder image service instead of real images.

If an event is clicked, show a details page.

That details page should have an add to cart button, and when that's pressed, the page should store that ticket in a cart.

Use a simple SQLite database for local storage and cookies to store the current contents of the cart.

Use HTML, CSS, and JavaScript, but no frameworks like React or Angular.  Use Node.js/Express for the backend.
